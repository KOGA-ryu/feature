# Markdown Formatting

## Purpose

Format plain text for notes, docs, prompts, and README work.

## Actions

- heading
- bold
- italic
- inline code
- code block
- quote block
- bullet list
- numbered list
- checklist
- link
- table stub
- reflow paragraph

## User Access Pattern

- toolbar for common markdown actions
- command palette for all actions
- keyboard shortcuts only where conventional and conflict-free

## Tests

- wrapping selection preserves selected content
- list toggles are reversible where possible
- code fences preserve indentation
- markdown formatting does not alter unrelated lines
