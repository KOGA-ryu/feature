# UI Harness Contract

The first UI harness is not the product. It is the testing bench.

Required layout:

- top bar: search, filter, run tests, open feature folder
- left panel: feature packs and feature list
- center panel: selected feature demo or documentation preview
- right panel: metadata inspector
- bottom panel: test runner output and activity log

The harness should help inspect and verify features, not become a second architecture project.
