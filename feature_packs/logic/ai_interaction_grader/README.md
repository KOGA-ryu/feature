# logic.ai_interaction_grader

`logic.ai_interaction_grader` turns a deterministic stream of AI interaction
events into a stable skill assessment.

V1 outputs:

- read quality
- timing
- control
- adaptation
- efficiency
- style
- overall band
- confidence

It is intentionally authored and replayable:

- no hidden difficulty scaler
- no machine learning
- no opaque score soup
