# ui.ai_grade_hud

`ui.ai_grade_hud` is the thin visible-feedback adapter for the simulation-zoom
AI grading lane.

It turns a grade card into:

- a visible skill band
- a confidence read
- a zoom-ready indicator
- a short teaching-oriented summary

V1 is intentionally light-touch. It should teach the mechanic without turning
the game into a spreadsheet.
